    How this page works
    1. Live status. The page asks the public Lanyard API for my Discord presence every 10 seconds: online status, avatar, Spotify and games.
    2. Custom tag. The small tag under my name is set with a /tag command in Discord and stored in Lanyard, so it shows even when I'm offline.
    3. GitHub card. When I push code, a card shows the repo and branch for 30 seconds. It reads GitHub's public events, so private repos never appear.
    4. Background. Every video in the background-videos folder is listed by a small function and played one after another with a crossfade.
    5. Hosting. It's one static page on Vercel plus a few small functions. There's no build step.
